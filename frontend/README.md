# KulaGraph Frontend

Intelligent family tree tracker with relationship inference.

## Features

✨ **Intelligent Inference**
- Auto-detect spouses from shared children
- Auto-detect siblings from shared parents
- Real-time relationship suggestions

🌙 **Dark Mode**
- Toggle theme with persistent storage
- Beautiful dark UI design

📊 **Graph Visualization**
- Interactive D3.js visualization
- Draggable nodes and zoom/pan
- Relationship type indicators

🔗 **Multi-Family Support**
- Connect different families through relationships
- Multiple users managing their own family trees
- Shared graph that grows as relationships are added

## Getting Started

```bash
cd frontend
npm install
npm start
```

The app will open at `http://localhost:3000`.

## Environment

Create `.env` file:
```
REACT_APP_API_URL=http://localhost:3001
```

## Build

```bash
npm run build
```
